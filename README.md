# Mini PDF Split 📚✂️

Uma ferramenta moderna, rápida e privada para dividir páginas duplas de PDFs digitalizados (comum em livros digitalizados "abertos").

![Mini PDF Split Preview](https://raw.githubusercontent.com/walterfr/mini-pdf-split/main/public/preview-placeholder.png) <!-- Nota: Você pode substituir por um screenshot real depois -->

## ✨ Funcionalidades

- **Divisão Inteligente**: Transforma 1 página de PDF (com 2 páginas do livro) em 2 páginas individuais sequenciais.
- **Privacidade Total**: O processamento é feito 100% no seu navegador usando `pdf-lib`. Seus arquivos nunca são enviados para um servidor.
- **Interface Premium**: Design moderno com *Glassmorphism*, modo escuro e animações fluidas.
- **Suporte a Cortes**:
  - **Vertical (Livros)**: Divide a página ao meio na vertical.
  - **Horizontal**: Útil para documentos digitalizados em paisagem.

## 🚀 Como Executar

Se você quiser rodar o projeto localmente para desenvolvimento:

1. **Instale as dependências**:
   ```bash
   npm install
   ```

2. **Inicie o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```

3. **Acesse no navegador**:
   Abra o link exibido no terminal (geralmente `http://localhost:5173`).

## 🛠️ Tecnologias

- [Vite](https://vitejs.dev/) - Build tool ultra-rápida.
- [pdf-lib](https://pdf-lib.js.org/) - Manipulação de PDF potente no lado do cliente.
- [Lucide Icons](https://lucide.dev/) - Ícones consistentes e bonitos.
- [Vanilla CSS] - Design personalizado sem frameworks pesados.
